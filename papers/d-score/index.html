第 0 章

热身：幻觉，和它的「内心戏」

大模型说得越流利，越可能在一本正经地胡说八道——问题是，它自己「心里」知道吗？

🤥 什么是「幻觉」？先分清两种说法

大语言模型会生成流利但虚假、或得不到证据支持的内容，这就是「幻觉」（hallucination）。论文先给出一个清晰的判定框架：把文本拆成一条条可核查的断言（claim）——比如「Transformer 架构发布于 2017 年」是一条断言，而「Transformer 比 RNN 更优雅」只是主观评价，不算。一条断言如果有证据支持就是 supported，否则是 unsupported；含有至少一条 unsupported 断言的文本，就被视为幻觉文本（论文 §1、§3.2）。

更关键的是论文提出的「模型内部幻觉」（model-internal hallucination）概念：一条断言不仅得不到外部证据支持，而且模型自己的内部状态里就藏着「这话不对劲」的信息（内部真值置信度低于容忍度 β）。换句话说：模型嘴上在胡说，心里其实有数（论文 §3.2 定义 2）。

像一个人撒谎时嘴硬、但眼神飘忽、心跳加速——「嘴上说的」和「身体反应」不一致。D-Score 干的事不是去审问他说的话，而是给他接上「测谎仪」，直接读他的生理指标。
本文检测的正是「模型内部可见」的那类幻觉：模型内部已经包含了识别错误所需的信息，只是没有体现在输出文本里（论文 §3.2）。

🧰 现有检测方法的三条路，都有点「绕」

在 D-Score 之前，主流的幻觉检测大致分三派：

路线代表方法思路代价
检索对比RAG 事实核查类拿生成文本去和外部文档比对需要检索系统和外部知识源
多次采样一致性SelfCheckGPT、语义熵（Nature 2024）同一个问题问很多遍，看答案互相矛盾不矛盾多次生成，推理成本成倍增加

本文的问题因此非常直接（论文 §1）：

能不能只靠「一次前向传播」产生的内部状态，直接判断这段文本是不是幻觉？——不检索、不采样多次、不训练新分类器。
第 1 章

数学基础：隐藏状态、SVD 与「谱」

看懂 D-Score 只需要三件数学道具：隐藏状态矩阵、奇异值分解、奇异值谱的形状。

① 隐藏状态：模型每读一个词时的「心理活动记录」

Transformer 模型每处理一个 token（大致相当于一个词或字），网络的每一层都会产出一个高维向量，叫隐藏状态（hidden state）——可以把它理解为模型读到这个词时，这一层「脑子里在想什么」的完整快照。设模型隐藏维度为 d、文本长度为 T 个 token，把第 j 层上所有 token 的隐藏状态排成一排，就得到隐藏激活矩阵（论文 §3.1）：

H(j)(x) = [ h1(j)(x)  ⋯  hT(j)(x) ] ∈ ℝd×T
每一列是一个 token 的「心理快照」，整个矩阵是模型读完这段话的「脑电图纸带」。对 7B/8B 级模型，d 是 4096 维，而 T 通常只有几百——矩阵又瘦又高。
隐藏状态矩阵就像一条心电图纸带：每个 token 是一个心跳采样点。医生（D-Score）不问病人「你感觉如何」（生成文本），而是直接读纸带的形状。

② 奇异值分解 SVD：把「脑电图」拆成若干层「主旋律 + 伴奏」

任何矩阵都可以做奇异值分解（SVD）：拆成一组互相垂直的「方向」，每个方向配一个奇异值 σ 表示这个方向携带的能量大小。按从大到小排列（论文 §3.1）：

H = UΣV⊤，   σ1 ≥ σ2 ≥ ⋯ ≥ σr > 0
σ₁ 是「最大方向」的强度；排在后面的 σ 越小，说明那个方向越可有可无。这一列从大到小的数，就叫矩阵的奇异值谱（spectrum）。
把合唱团录音做 SVD：σ₁ 是主旋律声部的音量，后面的小 σ 是和声、伴奏、呼吸声。如果整首歌基本只有一个主旋律（σ₁ 很大、其余迅速衰减），谱就是「尖」的；如果好几个声部音量差不多，谱就是「平」的。

③ 谱的形状 vs 谱的大小：为什么只看「比值」

D-Score 属于线性代数里「数值秩 / 有效秩」（numerical rank / effective rank）家族：不问你「绝对音量」多大，只问有多少个方向的音量「接近最大方向」（论文 §2、附录 A.2）。

论文严格证明了 D-Score 的两个「只看形状」的性质（命题 2）：

性质数学表述白话含义
缩放不变Dτ(c·H) = Dτ(H)整体音量放大 10 倍，结论不变——它看的是谱的形状不是响度
旋转不变Dτ(UHV) = Dτ(H)换个坐标系看同一份脑电图，结论不变
论文还证明 D-Score 与经典「稳定秩」（stable rank）满足 Dτ(H) ≤ τ²·srank(H)，把它锚定在了成熟的数值线性代数工具上（论文附录 A.2 命题 2）。
第 2 章

核心方法：D-Score 到底是什么

一句话：数一数隐藏激活矩阵里，有多少个奇异方向「和最大方向差不多大」——数得越多，幻觉风险越高。

📐 D-Score 的定义：一次「达标点名」

固定模型 m、层 j 和容忍参数 τ > 1。对输入文本 x，做一次前向传播拿到隐藏激活矩阵 H(x)，求出它的奇异值谱，然后（论文 §3.1 定义 1，式 (1)）：

Dτ(j)(x) = ∑i=1r 1{ σ1(H)σi(H) ≤ τ }
白话翻译：逐个方向检查「σ₁ 是 σi 的几倍」。倍数不超过 τ 的记 1 分，超过的记 0 分。总分就是 D-Score——达标方向的数量（一种相对数值秩）。
班里按身高排队，第一名是「标尺」。D-Score 问的是：有多少人的身高不低于第一名的 1/τ。如果队伍明显一高一矮，只有寥寥几人达标（D 小）；如果前排一片「差不多高」（D 大），说明能量没有集中在少数主导方向上。
D-Score 小 → 隐藏轨迹的变化集中在少数主导方向（文本「口径一致」）；D-Score 大 → 多个方向同时活跃且量级相当（文本内部「有多股力量在拉扯」）。这就是论文的核心假设（论文 §3.2 假设 1）。

🎛️ 亲手算一次：幻觉文本的谱为什么会「摊开」

论文的直觉是：当文本里包含一条与模型内部知识冲突的断言时，隐藏表示既要编码「文本声称的内容」，又要编码「反证、不确定、纠正信号」——这些额外信号会沿新的方向展开，把原本「尖」的谱摊「平」（论文 §3.2）。下面用两条示意谱演示（谱形状为教学构造，判定规则与论文一致）：

4.0
演示规则：正常谱 σi = 10×0.45i−1；幻觉谱在其基础上混入 3 个冲突方向（σ = 8, 6, 5.5，橙色柱）。蓝色虚线为阈值 σ₁/τ。判定阈值 D̄ = 4 为示意取值——实际部署中 τ、层 j、D̄ 都需在验证集上校准（论文 §3.1、§4.1）。
原本一个主旋律的合唱团里，混进了一支「跑调的第二声部」——指挥不用听懂歌词，光听「有几个声部音量接近主旋律」就知道队伍里出事了。

🚦 从分数到判决：阈值 D̄ 决定「松」还是「严」

有了 D-Score 这个标量，检测器只剩一步：选一个整数阈值 D̄，分数超过它就判幻觉（论文 §3.1 式 (2)）：

Ŷ = 1（幻觉） 若 Dτ(x) > D̄；否则 Ŷ = 0（正常）
τ 决定「多大的方向算达标」，D̄ 决定「几个达标方向算可疑」。两者都在验证集上校准后固定。

阈值往左移（更严，宁可错杀）：抓住更多幻觉，但误伤正常文本；往右移（更松）：漏掉更多幻觉。拖动滑杆体会这个权衡（数据为示意构造）：

🧭 为什么这能成立：冲突方向的严格论证

论文不是只讲故事，而是给了一个充分条件的数学命题：把隐藏轨迹拆成「连贯成分」S（处理文本声称的内容）和「冲突成分」C（内部可见的反证/不确定信号）。若 C 的奇异方向与 S 正交、σ₁(C) ≤ σ₁(S)，且 C 有 q 个奇异值 ≥ σ₁(S)/τ，那么（论文 §3.2 命题 1）：

Dτ(S + C) ≥ Dτ(S) + q
白话：每混进一个「够强且不重合」的冲突方向，D-Score 至少 +1。上面演示在默认 τ=4 时，幻觉谱正好从 2 涨到 5（+3），就是这条不等式取等号的情形。

论文同时坦承：正交假设是理想化的，真实模型里方向只是「统计上分离」；命题是充分条件而非幻觉表示的完整理论（论文 §3.2、附录 A.3）。附录 A.3 还补了一个概率分离结论：只要两类文本的 D-Score 分布大致分开，任何落在中间的阈值都有相应小的分类误差。

⚡ 算得起：不用完整 SVD，幂迭代数到「跌破线」就停

隐藏维度 d（4096 级）远大于文本长度 T，所以实际计算不碰 d×T 大矩阵，而是转成 T×T 的 Gram 矩阵 G = H⊤H——它的特征值正是奇异值的平方（论文 §3.3、附录 A.2 命题 2(iii)）：

Dτ(H) = ∑i 1{ λi(G) ≥ λ1(G)τ² }
Gram 矩阵版定义：数 G 有多少个特征值不小于最大特征值的 1/τ²。
做法代价说明
完整 SVDO(dT² + T³)把整个谱都算出来，浪费——我们只需要「在哪里跌破阈值」
幂迭代 / Lanczos 部分求解≈ O(Nit·K·dT)只从大到小恢复前 K 个特征值，一跌破 λ₁/τ² 就停；K ≪ T 时显著更省
不需要给全班排完整名次（完整 SVD），只需要从第一名往下数，数到「比第一名矮 1/τ 以上」的那个人就停（幂迭代提前终止）。
整个流程：一次前向传播 + 一次小规模谱计算，无外部验证器、无检索、无多次生成（论文 §6 结论）。
第 3 章

实验结果：三个模型、两个基准，全面领先

D-Score 在 FAVA-Annotation 和 RAGTruth 上、对 Llama-2-7B / Llama-3-8B / Vicuna-7B 几乎全面领先（唯一例外：RAGTruth 上 Llama-3-8B 的 TPR@5%FPR 略低于 Hidden Score，见表 2）。

🧪 实验怎么搭的

数据集：FAVA-Annotation（细粒度事实幻觉标注：实体错误、关系错误、矛盾陈述、虚构陈述等）和 RAGTruth（检索增强生成场景的幻觉语料，人工 span 级标注），均转成「响应级」二分类标签。

模型：Llama-2-7B、Llama-3-8B、Vicuna-7B。每个输入只跑一次前向传播，取单层隐藏状态计算 D-Score（奇异值用幂迭代高效估计）。

指标：AUROC（分数排序能力）、Accuracy 与 F1（配合阈值 D̄）、TPR@5%FPR（误报率压到 5% 时的幻觉召回）。基线：困惑度 PPL、窗口熵、Logit 熵，以及最接近的隐状态谱方法 Hidden Score（来自 LLM-Check，论文 §4.1）（论文 §4.1）。

担心结果是某个「神仙参数组合」碰出来的？论文附录 C 用 Llama-3-8B 在 FAVA 上扫描了 τ（横轴，细密取值）× 层 j（纵轴，覆盖全部 32 层）的完整热力图：一大片相邻配置的 AUROC 都差不多，性能随参数平滑变化而不是断崖式跌落（论文附录 C 图 1）。

好比相机的对焦环：不是只有某个精确刻度才清晰，而是一整段区间内画面都可用——部署时在验证集上选一个合理配置固定下来即可。
第 4 章

局限与意义

论文自己的态度很克制：D-Score 是「校准过的风险信号」，不是「真理检测仪」。

⚠️ 四条明确的局限（论文 §5）

局限含义
需要白盒访问必须能拿到隐藏激活，闭源 API 模型直接用不了
只能测「内部可见」的幻觉如果模型内部根本没有识别错误的知识（不是「模型内部幻觉」），谱上不会留下痕迹
复杂正常文本也会「摊谱」长、多样、语义复杂的文本同样可能激活多个方向 → 可能误报。D-Score 高 ≠ 一定有错
分数范围随文本长度变化Dτ(x) ≤ T（token 数），部署时可能需要按长度分层校准阈值

此外，论文报告的是「每个模型取最优层」的诊断性结果；实际部署应在留出校准集上选定层、τ、D̄ 后固定（论文 §4.1、§5）。

🌟 为什么这项工作值得读

在「幻觉检测」这个越来越依赖重型外挂（检索器、验证模型、多次采样）的领域里，D-Score 反其道而行：把问题还原成一行线性代数。它的价值不在于数字本身多高（AUROC 60+ 离实用还有距离），而在于证明了一件事——

「有多少个奇异方向与最大方向相当」这个极简的几何量，本身就携带幻觉风险信息。不需要训练、不需要外部资源、一次前向传播即可提取（论文 §6）。

论文给出的未来方向也很具体：与语义熵、一致性检测、探针分类器等更全基线对比；逐层曲线与跨数据集阈值迁移实验；按长度分层的结果分析；token 级 / span 级的局部 D-Score（定位幻觉出现在回答的哪个位置）（论文 §5）。
