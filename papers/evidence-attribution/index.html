看懂证据归因：答对了却指错地方？问题不在「眼睛」，在「嘴上」

阿尔托大学团队发现：让视觉语言模型用坐标框指出答案的证据区域时，即使答案正确，召回率也几乎为零——这不是能力缺失，而是「坐标接口」本身的表达瓶颈。改用模型最擅长的自然语言原文引用＋检索定位，证据召回从最多 8.1% 跃升到 26%–47%，幻觉率大致减半；再叠加一套不需要任何区域标注的 GRPO 训练，8B 模型的严格归因准确率从 22.4 提到 33.8。

第 0 章

热身：什么是「归因失效」

模型答对了问题，却指错了证据所在的位置——在金融、法律、医疗场景里，这等于没说。

📄 任务：答案必须「有据可查」

视觉文档理解的任务设定是：一份文档 D 是 N 页页面图像的序列 (p1, …, pN)，给定问题 q，系统不仅要给出答案 y，还要给出引用集 C = {(kj, bj)}——每条引用是「第几页 k + 页上一个边界框 b」。判定引用是否命中标准答案的证据框，用的是目标检测里的经典指标 IoU（交并比）：两个框重叠面积占并集面积的比例，同页且 IoU ≥ 0.5 才算命中（论文 §3）：

IoU(b, b*) = |b ∩ b*||b ∪ b*| ≥ 0.5  ⟹ 命中（hit）
白话翻译：你画的框和标准答案的框，重叠部分要占到两框总面积的一半以上。论文还区分「页级定位」（找对页）和「元素级定位」（找对页上的段落/表格/图）——标注粒度是元素级。
像法庭上的证人：光说出「凶手用的是磷青铜」不够，还必须走到物证柜前，把那份证据指出来。答对案情却指错物证柜，证词依然不可采信。

此前的主流做法是坐标接口：模型直接输出边界框的坐标数字。但在 CiteVQA 这类基准上，开源模型暴露出诡异的现象——答案分可以很高（最高 91.8），证据召回却几乎为零（最好也只有 8.1%），这种「答对却指错」被称为归因幻觉（Attribution Hallucination）（论文 §1、§4）。

本文要回答两个层层递进的问题：① 这个失败是模型没有定位能力，还是坐标这种「说法」表达不出来？② 能不能在不依赖昂贵区域标注的前提下，把归因能力练出来？（论文 §1）

第 1 章

概念基础：基准、语义块与指标家族

看懂后文只需三件道具：CiteVQA 评测怎么搭、版式解析器切出的「语义块」、以及六个评分指标。

🗂️ CiteVQA 与「已验证评测集」

评测基于 CiteVQA（GitHub）的单文档部分——一个要求模型同时给出答案和元素级框引用的双语基准。论文只做了一件谨慎的事：剔除源 PDF 已失效或标注与文档对不上的题目，留下 987 题中的 719 题（72.9%），覆盖 440 份 PDF，页数中位数 34 页、最长 182 页。由于筛选只看标注和文档内容、不看模型输出，对两种接口一视同仁（论文 §4、附录 B）。

标注把证据分成两类：必要元素（necessary）——任何正确答案都必须引用；附加支持元素——引了不加分、但也不算错。这个区分会直接影响下面指标的定义。

评测的六个模型覆盖四个家族、8B–31B：Qwen3-VL-8B / Qwen3-VL-30B-A3B、Qwen3.5-9B / Qwen3.5-27B、Gemma-3-12B、Gemma-4-31B，涵盖 dense 与 MoE、thinking 与非 thinking 变体（论文 §4）。

🧱 语义块：版式解析器切好的「候选货架」

语言接口的关键配角是版式解析器（layout parser）。论文用 MinerU 把每页文档切成一组带类型的语义块（semantic blocks）：段落、表格、图、图注……每个块 β 自带页码 k(β) 和边界框 b(β)，全部块的集合记作 B(D) = {β1, …, βn}（论文 §3.2）。

超市理货员提前把整本长文档分格摆上货架（每格贴好「页码+位置」标签）。模型不用再背坐标，只需说出「我要的那件商品长什么样」，检索器去货架上把最像的那格取下来——格子的标签就是引用框。

注意一个重要的 honest trade-off：既然引用框只能从货架格子里选，就存在解析器上限（parser ceiling）——即使检索完美，召回也只能达到 88.2%（IoU 0.5），因为有些标注元素和任何块的边界都对不齐。论文用独立的解析器 Docling 复测（上限 87.8%），确认这是文档属性而非某个解析器的偏见（论文 §5.2、附录 E）。

🚥 指标家族：两个几何分 + 两个裁判分 + 两个综合判决

指标定义（白话）看点
Rec 召回必要证据元素里，被同页 IoU≥0.5 命中的比例（宏平均）「该指的指到了多少」
Prec 精确率模型引用的框里，命中任意标注证据（含附加元素）的比例「指的东西有多少是靠谱的」
Rel 相关性裁判模型给证据相关性打 0–5 分（报告时 ×20）裁判读了引用区域的裁剪图
Ans 答案质量裁判模型给答案打 0–5 分（×20）答得好不好，与指得准不准分开算
SAA 严格归因准确率见下方公式「答对 且 指对」的比例
AH 归因幻觉率 ↓见下方公式「答对了却指不对」的比例，越低越好
SAA = 1[ Ans ≥ 4 ∧ ( Rel ≥ 4 ∨ Rec ≥ 0.6 ) ]   ;   AH = ℙ( SAA = 0 | Ans ≥ 4 )
白话翻译：SAA 要求「答案好（≥4 分）并且证据站得住（裁判相关性 ≥4 分 或 几何召回 ≥0.6）」。AH 则在所有答对了的题里，统计归因不达标的比例——这正是「答对却指错」的严格量化（论文 §4）。评测裁判是 Gemini-3.5-Flash，与训练奖励裁判不是同一个模型。
SAA 像驾照考试的「双科联考」：笔试（答案）和路考（指认）都过才算过。AH 则专门统计「笔试满分、路考挂科」的比例——挂科率最高时达到 97%。
第 2 章

核心方法：把「指认」拆成「复述 + 检索」

模型只负责用它最擅长的语言说出证据原文；把这段话「落」到页面区域上的脏活，交给检索管线。

🗣️ 语言接口：证据就是「原文引用」

对比坐标接口 C = fθ(q, D)（模型直接吐坐标数字），语言接口让模型输出一个 JSON：一段自由答案 + 一组逐字引用（verbatim quotes） U = fθ(q, D)。每条引用必须是从某个页面区域原样摘抄的片段，粒度可以是句子、表格行、表格单元格、图注或脚注（论文 §3.1）：

坐标接口：C = fθ(q, D)     语言接口：C = A( f(U), f(B(D)) )
白话翻译：f 把「引用」和「候选语义块」都变成向量，A 做一对一指派。模型只产出文字 U，引用集 C 在模型之外装配出来。

为什么必须「逐字」而不能「自由描述」？因为一段图注、一个单元格在整本文档里几乎是唯一的，检索时一锚一个准；而对一张图的自由描述可能匹配到任何主题相似的图。这个设计还顺带解决了非文本证据：表格和图通过它们的标题、单元格、注释来引用——文档里约三成证据本来就是非文本的（论文 §3.1、§3.2）。

自由描述像跟图书管理员说「找一本讲人工智能的红皮书」——可能抱来一堆；逐字引用则像报出书里的一句原话——图书馆员按全文检索一翻就定位到那一页那一行。

🔍 检索管线：裁剪图嵌入 + 匈牙利一对一指派

引用怎么「落」到块上？四步流水线（论文 §3.2，式 (1)）：

步骤做什么关键细节
① 切块MinerU 把每页切成语义块 β1…βn每块带页码和边界框
② 嵌入每块渲染成裁剪图，用多模态编码器（Qwen3-VL-Embedding-2B）转向量；每条引用同编码器转向量嵌「图」而非「提取出的文本」——约 30% 证据是非文本的，渲染表格与纯文字引用在文本空间里相似度很低
③ 全文候选在整本文档所有块里算余弦相似度 Sjℓ = cos(f(uj), f(βℓ))故意忽略模型自己预测的页码（不可靠），避免页码错误变得不可挽回

🏋️ 不用区域标注的训练：GRPO + 「答案门控」奖励

区域级证据标注对长文档极贵。论文的巧思是：把上面这条「引用-检索」管线原封不动地当成训练脚手架——奖励完全由现成材料算出：问题、模型答案、标准答案（不是区域标注！）、以及检索回来的块裁剪图。一个 VLM 裁判看这四样东西，打三个 0–5 的整数分：答案正确性 a、证据相关性 erel、证据覆盖度 ecov。裁判看的是裁剪图而不是引用原文——这样「引用得流利但配错了块」照样得低分，奖励与框级评测对齐（论文 §3.3）。奖励定义（式 2）：

r = a5 · erel + ecov10
白话翻译：证据分（满分 1）先被答案分（a/5）乘性门控——答案错了，证据再好也是 0 分，精准对应「归因幻觉只发生在答案正确时」的设定；两个证据分相加，则保证组内奖励有足够的方差，GRPO 才有梯度信号（论文 §3.3 式 (2)）。

第 3 章

实验结果：换个「说法」，能力就回来了

同一批模型、同一批题，只改证据的表达方式：召回率提升近一个数量级，幻觉率大致减半。

📉 阈值实验：坐标丢掉的是「几何」，不是「页码」

把 IoU 要求从松到紧逐步上调，两种接口的命运截然不同。以 Qwen3-VL-8B 为例（论文 §5.2 Figure 3、附录 Table 4）：坐标接口从页级召回 30.7% 崩到 IoU 0.1 的 5.8%、IoU 0.7 的 0.0%——模型常常找对了页，却画不对框；语言接口则从 42.3% 到 39.2% 几乎拉成一条平线——因为引用继承的是解析器块的天然几何，一旦配对正确，天然就是元素级精确。拖动滑杆看三个阈值下的读数：

+snap：把坐标框「贴」到同页重叠最大的块上阈值崩塌消失，但召回仍只有 5.0%–23.5%，被各自的页级召回封死——粒度不是缺失的那块拼图，页码才是
q / q+a：不用引用，改用问题（+模型答案）当查询检索仅问题检索每个骨干都输给引用管线 13–19 分；加上答案后差距大幅收窄——说明位置信息本来就编码在模型生成的语言里。但两种读法常命中不同的块：引用额外贡献 11.1 分覆盖，引用通道并不可省（附录 F）
lex：同样的引用，用词面/BM25 匹配代替裁剪图嵌入掉 5–14 分——多模态嵌入能解析「改述的引用」，不只靠原文照抄
消融总结论：恢复出来的归因能力，靠的是模型自己生成的那几段语言——检索部件只是把它「翻译」成几何位置（论文 §5.3）。

🚀 训练效果：8B 模型不花一分区域标注钱

召回率 39.9 → 51.3；SAA 22.4 → 33.8；AH 41.2 → 28.4；页级召回 63.2 → 73.8，各 IoU 阈值均匀提升；评测裁判给相关性和答案质量都打了更高分（论文 §5.4）。
代价：每条回答引用数 2.1 → 4.6 个，引用精确率 37.6 → 26.5，框 F1 32.2 → 28.8 不升反降——部分召回提升是「多引用」买来的（论文 §5.4）。

多出来的引用是噪声吗？标注本身说不清（精确率把标注外的一切都算错）。独立裁判给出更干净的信号：在更严格的 SAA 变体（Ans≥4 ∧ Rel≥4，去掉召回析取项）下，训练模型从 19.1 提到 27.4（McNemar p = 6×10⁻⁷）——多引的区域大多落在标注未覆盖但确有支持作用的材料上，策略是在认真改进引用，而不是钻奖励的空子（论文 §6.3、附录 D）。

残留错误分析还显示：训练前的漏召回大头是「模型根本没引用」而非检索排错序，训练的召回增益几乎全部来自这一类别——这正是奖励里覆盖度项 ecov 的设计目的（论文 §6.3、附录 H）。

训练前学生答题只翻一页课本；训练后学会「多翻几页、页页相关」——翻得多导致偶尔翻到无关页（精确率降），但裁判确认大多翻得对。奖励里的「覆盖度」就是在鼓励「该翻的页别落下」。
第 4 章

讨论与局限：不是学不会，是没学过

坐标归因的失败是「接口伪影」而非「能力鸿沟」——但这条路线也有自己的天花板和代价。

🧭 三个支持「接口伪影」判决的证据

证据内容
① 换接口即恢复若模型真的缺定位能力，换接口不该有用；实际上召回提升近一个数量级。四个家族、四倍参数量跨度上模式一致——最强的坐标答题者仍有 82.1% 的正确答案指错证据，堆参数救不了坐标归因（论文 §6.1）
② 阈值分解坐标框丢的是区域几何、不是页码——预测框往往是「大致正确区域」周围的粗糙矩形（论文 §6.1）
③ 模型「自发」用语言坐标提示下，Qwen3-VL-30B-A3B 只有 33.1% 的回答能解析出框；人工检查发现其余回答不是拒答或截断，而是答完题后直接用语言描述位置——页码、章节标题、表名。被要求说坐标时，模型常常擅自切换成了本文提出的语言接口（论文 §6.2）

坐标格式并非「不可学」：闭源的 Gemini-3.1-Pro 用同样的坐标格式达到 68.9 召回、76.0 SAA（CiteVQA 完整单文档集、不同裁判，仅供参照）；自然图像上的检测式坐标输出也早已成功。结论是「不是学不会，而是没学过」——缺少专门定位监督的开源模型，用坐标失败、用语言成功（论文 §6.1、附录 Table 5）。

开源模型像一个心里门儿清但从没练过默写地图坐标的向导：逼他写坐标就出错，让他用嘴描述路线反而头头是道。闭源大厂给向导专门补过「坐标课」，所以人家能写对——这是训练覆盖的差异，不是智力的差异。

局限具体表现出处

意义：这项工作把「归因失败」从「模型能力问题」重新定性为「接口与监督问题」，并给出一条实用路线——不需要坐标接口、不需要昂贵的区域级监督，仅靠标准答案 + 检索管线做奖励，就能持续提升开源 VLM 的证据归因（论文 §7）。对金融、法律、医疗这类「答案必须可核查」的场景，这意味着可信文档智能的门槛显著降低。
