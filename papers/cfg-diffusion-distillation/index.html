看懂 CFG 下的扩散蒸馏：两个分支误差互相抵消，训练目标却浑然不觉

阿里 Qwen 团队重新审视 on-policy 蒸馏（OPD）与 classifier-free guidance（CFG）的组合：只匹配「引导后的合成速度」在分支层面是欠约束的——正、负分支的误差可以互相补偿。当教师的负分支掌握学生拿不到的特权信息时，这种补偿会演变成「负分支不对称」（NBA）：正支误差在降、负支误差却在涨。解法是把监督提前到合成之前：正支预测 + CFG 方向分别对齐（PDM）。

第 0 章

热身：扩散、CFG 与蒸馏

先用三个生活场景，把论文用到的三个积木摆上桌。

🌫️ 扩散模型：从一团噪声里「雕」出画面

扩散模型的生成过程像一位雕塑家：起点是一块「噪声原石」（纯随机像素），模型一步步预测「该往哪个方向削」，每一步都把画面往目标推一点，几十步之后，清晰的人像、文字、视频就从噪声里浮现出来。这个「每步该往哪走」的预测，论文里统一用速度（velocity） v 来表示——它是模型在某个含噪状态 xt、某个时刻 t、某个条件 c 下给出的局部行进方向 论文 §2.1。

「蒸馏」则是让一位教师（更强或掌握更多信息的模型）带一位学生（更弱或信息更少的模型）：学生在某个状态下给出自己的方向，教师在同一状态给出参考方向，训练目标就是让学生的方向向教师看齐。

学书法：你（学生）临帖写得歪歪扭扭，老师（教师）握着你的手在同一个字上示范一遍正确的运笔方向。你不需要重来整张纸，只需要在「写到一半的这个位置」把笔锋调对——这就是逐状态的方向匹配。

🎚️ Classifier-Free Guidance：两个「导航员」再加一档力度旋钮

现代扩散系统几乎都用 CFG（classifier-free guidance， Ho & Salimans 2022）来让生成更贴合提示词。关键事实：CFG 实际去噪用的那个速度，从来不是网络直接输出的。网络要跑两次——一次带目标文本条件（正分支 v+），一次带空文本或负面条件（负分支 v−），然后按引导强度 γ 合成 论文 §1, 式 3：

ṽ = γv+ + (1 − γ)v−
白话翻译：正分支说「往提示词那边走」，负分支说「别往泛泛的方向走」。γ = 1 时只剩正分支；γ > 1 时，相当于从负分支出发、沿「正 − 负」的方向走过头 γ 倍——过冲越多，越贴题但也越容易崩坏。γ 是推理时才拧的旋钮，训练时往往还没定。

示意向量。蓝箭头 = 正分支 v₊（朝提示词），灰箭头 = 负分支 v₋，黄箭头 = 合成速度 ṽ。注意 ṽ 的起点在 v₋ 的箭头尖上，沿 v₊−v₋ 方向延伸 γ 倍——这就是「从负分支出发走过头」。
两个导航员：正导航员说「目标在东北方」，负导航员说「千万别走西南那条烂路」。CFG 的做法是：先听负导航员指出烂路，再朝着「目标方向 − 烂路方向」多走 γ 倍。γ 拧得越大，车开得越猛——贴题，但容易冲出路面（画面 artifacts）。

🏃 On-Policy 蒸馏：在学生「自己走到的状态」上请教师点评

传统（off-policy）蒸馏在「数据构造的状态」上训练——比如给真实图片加噪得到的标准含噪状态。而 on-policy 蒸馏（OPD）让学生用自己当前的策略生成完整去噪轨迹，教师只在学生实际访问过的状态上做评估并给出监督 DiffusionOPD D-OPSD Flow-OPD。这样监督恰好覆盖学生真正会犯错的地方，再叠加每一步都有的稠密反馈，成为离线蒸馏和标量奖励优化之外的有力选择 论文 §1。

驾校教练的两种方式：off-policy 是让你在模拟器里看「标准路况录像」练反应；on-policy 是教练坐副驾，你自己开车上路，在你真实开到的每个路口，教练立刻告诉你「刚才方向盘该往哪打」。后者教的就是你实际会遇到的状况。
OPD 的目标在学生访问的状态 xtS 上最小化师生预测差异，化简后（差一个时间步权重 w(t)）就是速度匹配：‖vT − vS‖² 论文 式 2。教师可以看到学生拿不到的特权信息，因此双方条件 cT、cS 不必相同——这一点是后面所有故事的伏笔。
第 1 章

概念基础：当 OPD 遇上 CFG

把上一章的两个积木拼起来，裂缝就出现了：合成后的速度可以匹配，两个分支却可能各错各的。

🧩 最自然的做法：匹配「合成之后」的速度

面对带 CFG 的教师，一个最自然的扩展是：师生各自算出自己的正、负分支，各自按 γ 合成，然后匹配合成结果 论文 式 5。记两个分支各自的误差为 e+ = vT+ − vS+，e− = vT− − vS−，则朴素目标只约束它们的线性组合：

Lnaive ∝ ‖ γe+ + (1 − γ)e− ‖2
白话翻译：只看「按 γ 加权后的总账」。只要 γe₊ + (1−γ)e₋ 这一项为零，损失就是零——至于 e₊ 和 e₋ 各自是多少，损失函数根本不关心。

问题在于，一个向量等式 γe+ + (1−γ)e− = 0 约束的是两个未知向量，方程个数不够——这就是论文说的「分支层面欠约束（under-identified）」 论文 §2.2–3.1：

e+ = γ − 1γ e−
式 7：只要正支误差与负支误差保持这个固定比例，合成预测就分毫不差。满足条件的 (e+, e−) 有无穷多组——两个误差可以互相补偿，而训练目标毫无察觉。
小组作业只算总分：正支是「策划」、负支是「执行」，期末只看合成总分。策划多扣 7 分、执行多挣 7 分，总分纹丝不动——老师完全看不出两个环节各自已经偏得离谱。更糟的是，换一位用不同权重（另一个 γ）的评委来合分，藏着的偏科立刻露馅。

欠约束本身不等于失败。论文强调：如果师生负支条件相同，共享参数的更新可以让两个分支误差一起下降，朴素匹配依然有效；真正出问题的是教师负支握有特权信息的情形 论文 §1, §3.1。下一章用两组对照实验把这件事讲清楚。
第 2 章

核心发现：负分支不对称（NBA）

同一套朴素目标，在两种负支条件下走向两种命运：良性联合下降，或拮抗此消彼长。

📉 拮抗动力学：正支在进步，负支在退步

论文全程追踪训练中的两条分支误差曲线（论文图 2）。共享负支时一切正常：甚至只做正支匹配，负支误差也会跟着降——正支更新顺带惠及负支；朴素匹配与 PDM 都是两个误差联合下降。特权负支时剧情反转：朴素匹配（和只做正支的消融）让正支误差下降的同时，负支误差持续上升——论文称之为拮抗性分支误差动力学，即 NBA（Negative Branch Asymmetry） 论文 §3.1, 图 2。

动画 ③ · 两种命运：联合下降 vs 拮抗此消彼长
示意曲线，复现论文图 2 的趋势形态（数值为教学演示）：蓝线 = 正支误差 ‖e₊‖，红线 = 负支误差 ‖e₋‖，左面板 = 朴素匹配，右面板 = PDM。特权负支下，朴素匹配的负支误差一路上扬，而 PDM 通过分别约束正支预测与 CFG 方向，掐断了补偿通道。
跷跷板式做账：朴素目标只看「γe₊ + (1−γ)e₋」这个合成值。正支误差往下一压，只要负支误差按固定比例往上一抬，合成值照样漂亮——训练看起来一路向好，负支其实已经悄悄烂掉。等到推理时换一个 γ 重新配比，跷跷板的平衡被打破，问题立刻显形。

🩺 NBA 的诊断特征：看「超额退化」，不看绝对退化

换 γ 后性能下降本身并不能证明 NBA——教师自己可能就内在地依赖 CFG。论文给出的判据是超额退化：学生在换 γ 后偏离了教师的 γ 响应曲线，或比分支感知（branch-aware）的同类学生退化得更多 论文 §3.1, §4.1.3。

文字渲染（共享负支）的 γ 扫描证明了这一点：γ=1 时教师、朴素学生、PDM 学生的 OCR 奖励分别是 75.24 / 73.87 / 74.48，三者随 γ 增大同步改善——退化是教师「与生俱来」的，两种目标都没有引入额外敏感 论文 表 1。而参考条件蒸馏（特权负支）里，教师在 γ∈{1, 1.5, 2, 2.5} 全程保住参考风格，PDM 紧密跟随，朴素学生却在 γ=1 时出现明显的视觉失真与风格漂移（论文图 3） 论文 §4.1.3。

论文结论（Finding）：分支歧义何时有害？共享负支 → 联合下降，学生紧跟教师内在的 CFG 响应；特权负支 → 朴素匹配引发拮抗动力学与超额 γ 敏感，PDM 两者都压住。NBA 的签名是「相对教师或相对分支感知学生的超额退化」，而不是绝对的 CFG-free 性能下降 论文 §4.1.3。
第 3 章

核心方法：PDM 与高效监督

解法一句话：别等合成完再对账，在合成之前就把「正支预测」和「CFG 方向」分别对齐。

🎯 Positive–Direction Matching：把监督提前到合成之前

对模型 M ∈ {教师, 学生}，定义它的 CFG 条件方向为两个分支之差 论文 式 9：

dM = vM+ − vM−
白话翻译：d 就是动画 ① 里「从负分支指向正分支」的那根向量——它刻画「提示词到底把方向推了多远」，正是 CFG 在 γ > 1 时过冲所沿的方向。

主目标 PDM 分别匹配正支预测和这个方向 论文 式 10：

ℓPDM = ‖e+‖2 + λ ‖dT − dS‖2 = ‖e+‖2 + λ ‖e+ − e−‖2
逐项翻译：第一项锚定正分支（学生正支必须真的像教师正支）；第二项保住 CFG 方向（正负支的「差距」必须一致）。两项联立的唯一零解是 e+ = e− = 0——补偿自由度被彻底消除，再也不可能「保一个、烂一个」。

作为对照，论文还设计了 IBM（Independent Branch Matching）：直接分别匹配两个分支，权重保留朴素目标展开后的 γ² 与 (γ−1)²，但去掉交叉项 论文 式 11。PDM 与 IBM 在 γ > 1 时都有唯一的分支级零解；实验上 PDM 整体更强（见第 4 章），但论文坦承这一优势目前只是经验性的。

动画 ④ · 两种目标训练后，学生的分支长什么样
示意向量（γ = 4.5）。细箭头 = 教师（蓝 v⁺T，灰 v⁻T），粗箭头 = 学生。朴素训练后：合成速度 ṽ 与教师几乎重合，但两个分支各自偏移、误差互相补偿；PDM 训练后：正支逐一对齐、方向 d（虚线）保持一致，分支误差无处遁形。
从「只看总分」改成「分项批改」：朴素目标是期末只看合成总分；PDM 相当于既批改「策划卷」（正支），又单独核对「策划与执行的分差」（CFG 方向）。两张卷子都对了，任何权重的评委（任何 γ）合出来的分都对。

第 5 章

局限与意义

这篇论文最大的贡献不是一个新的 loss，而是把一个「默认正确」的组合拆开检查了一遍。

⚖️ 论文自己承认的局限

PDM 与 IBM 在非退化权重下共享同一个分支级零解，PDM 观察到的优势目前是经验性的、没有理论解释——两者优化行为的差异尚待刻画。NBA 的分析也有待推广到其他引导机制（如把 CFG 内化进单预测的 DanceOPD 式学生）和其他师生条件不对称的情形 论文 §6。此外参考条件蒸馏的案例是定性的（12 条 held-out 提示词），作者明确不把它当作性能的聚合估计 论文 附录 7.1.2。

🌍 为什么这件事重要

CFG 是几乎所有现代扩散系统的默认组件，OPD 正在成为扩散模型后训练的热门范式——两者的组合方式是「顺手为之」的：把速度匹配扩展到合成预测上，看起来天经地义。这篇论文证明这个顺手的选择在数学上欠约束，并且精确指出了它何时 benign、何时咬人：只要教师负支握有学生拿不到的特权信息（参考图、稠密控制……这在实际知识迁移里非常常见），朴素匹配就会把负支越练越烂，而且在训练用的 γ 下完全看不出来。

给实践者的行动清单也很直接：做 branch-retaining 的 OPD 时，先检查师生负支条件是否一致；不一致就换分支感知目标（PDM 或 IBM）；部署时若需要在多个 γ 下工作，务必做跨 γ 评测——训练 γ 下的好成绩可能是一场「主场幻觉」 论文 §1, §4.2.3。

一句话总结：对账要在合成之前。正支预测 + CFG 方向分别对齐（PDM），损失为零当且仅当两个分支都对——补偿自由度归零，γ 随便换 arXiv 摘要 项目主页。
