第 0 章

热身：为什么要给规划能力做「物理实验」？

大模型的规划能力像一锅成分不明的汤——想改进它，得先有一个每种配料都能精确控制的小灶。

🧩 核心问题：能力到底从哪来？

让智能体「给我织一件羊毛衫」，它需要：拆解目标 → 追踪背包里有什么 → 记住「草籽+水→草、羊+草→羊毛」这类合成规则 → 在十几步内按正确顺序执行。这就是多轮长程规划（multi-turn long-horizon planning）。OSWorld 2.0、DeepPlanning 等基准都表明：现有大模型短任务还行，长程任务显著吃力（论文 §1）。

但想改进它却无从下手：现有基础模型都训练在不可控、不透明的互联网数据上——没人说得清长程规划能力是预训练时就有、还是后训练「激活」的。论文把这个问题拆成三个递进的子问题（论文 §1）：

训练阶段子问题对应章节
① 大规模预训练规划能力如何习得（世界模型内化 / 原子技能组合 / 轨迹质量）§4
② RL 后训练规划能力如何被 GRPO / OPD 塑形，适用边界在哪§5
③ 多教师合并规划能力如何整合：跨环境泛化、持续学习、冲突解决§6
想知道「好厨子是怎么炼成的」，光品尝成品（评测大模型）没用——你得开一家实验厨房：食材、菜谱、学徒全都自己配，才能分别测试「选材重要还是刀工重要、跟几个师傅学会不会串味」。这篇论文就是开了这样一家厨房。
论文图 1 里藏了个彩蛋：用🦒长颈鹿代表 Long-Horizon 的「L」——长脖子象征智能体在长程规划中需要「看得远」（论文图 1 说明）。
第 1 章

概念基础：炼金实验室、两类「脑内资产」与两位教练

看懂全文只需要三件套：一个可控合成环境、一对「模式 vs 知识」的概念、两种后训练算法。

① 可控规划健身房（Controllable Planning Gym）

作者构建了三个合成领域：幻想炼金（Fantasy Alchemy）、畜牧养殖（Livestock Farming）、电子装配（Electronic Assembly）。每个领域是一棵 5 层的「技能图」：每层 40 个物品类目、每类 20 个具体实例（如「草籽」类目下有「turf seed」等实例），共 200 个类目、4000 个物品名（论文 §3.1、附录 A.2 表 10）。

低层物品按 AND/OR 逻辑合成高层物品——一个目标可以有多条独立配方（OR），每条配方需要集齐全部原料（AND）（论文 §3.1 式 (6)）：

v ⟸ ( u1,1 ∧ ⋯ ∧ u1,k₁ ) ∨ ⋯ ∨ ( um,1 ∧ ⋯ ∧ um,km )
白话：想合成物品 v，任选一条配方（∨ = 或），但配方里的每样原料都得备齐（∧ = 与）。

任务：给智能体一个初始背包（原料 + 2~4 个干扰项），让它在有限步数内合成目标物品。难度按最少步数分级：Short 1~5 步、Middle 6~8 步、Long ≥ 9 步（论文 §3.1、§4.2）。评估：3 域 × 3 难度，每个子集 160 个实例，共 1440 个/ checkpoint；温度 0.4 独立采 8 条轨迹，报 avg@8（平均成功率）与 pass@8（8 次至少成 1 次），单 checkpoint 最多 11,520 次推理（论文 §3.3、图 3 说明）。

这就是 Minecraft 的合成台：给你一背包材料（还混了几个没用的），问「能不能 15 步内做出羊毛衫」。会做单个配方（草籽+水→草）是「原子技能」，把 15 个配方串成一条链才是「长程规划」。
实验用的学生模型是从零随机初始化的 Qwen2.5-100M（12 层、隐藏维 768、GQA、词表仅 3000），预训练语料约 1.2B token，9000 步、2 张 GPU——一切成分透明可控（论文 §4.1、附录 A.1/A.4）。

② 规划模式 vs 规划知识：方法论与菜谱

论文把规划能力拆成两种「脑内资产」，这是理解后半篇全部结论的钥匙（论文 §4.3、§5.1）：

规划模式（Pattern）规划知识（Knowledge）
是什么CoT 的结构骨架：先定目标、递归拆解、检查背包、再输出动作（DFS 式思维模板）任务特定的配方：「晶谷微粒 + 辉光蕨 → 石英溶液」这类具体合成规则
跨任务性通用，跨样本共享专用，每个任务可能不同
互信息I(T;P) 低——知道任务 T 不太能推断用哪个模式I(T;K) 高——任务几乎决定了需要什么知识
I(T;P) = H(P) − H(P|T)   <   I(T;K) = H(K) − H(K|T)
互信息衡量「知道任务 T 能减少多少不确定性」。模式是通用的方法论（低互信息），知识是绑死任务的具体配方（高互信息）。这条不等式是第 3 章「三区域」结论的理论起点（论文 §5.1 式 (10)）。
模式是「做菜的方法论」——先看菜单、盘点冰箱、按步骤下锅，放之四海皆准；知识是「具体菜谱」——麻婆豆腐放几克花椒。方法论可以一通百通，菜谱必须逐条硬背。后面会看到：RL 擅长塑造方法论，却灌不进菜谱。

③ 两位教练：GRPO「只看期末总分」，OPD「逐题批注」

后训练阶段的两位主角（论文 §2.2、§5.2.1）：

算法监督信号特点
GRPO二元结果奖励：一整条 15 步轨迹走完，只告诉模型「成了 / 没成」稀疏奖励，功劳/黑锅要在长轨迹里分配（credit assignment）
OPD（On-Policy Distillation）逐 token 稠密监督：学生在自己走出的轨迹上，每个 token 都对齐教师的概率分布（reverse KL）每一步都有人批改，但前提是教师足够好
ℒAgent-OPD(θ) = 𝔼τ∼πθ [ ∑k=1K ∑t=1Tk DKL( pk,t ‖ qk,t ) ]
白话：学生先自己动手做一整轮（on-policy），然后教师对学生写下的每个词给出「要是我会怎么写」的概率分布，学生逐个词缩小与教师的差距（KL 散度）。本文多轮 OPD 采用 Top-k 截断（k=100）（论文 §2.2 式 (2)、§5.2.1）。
GRPO 像只看期末总分的教练：15 道题做成一锅，最后一句「59 分」——学生不知道哪道题丢的分。OPD 像坐在旁边的私教：学生每写一步，老师就批注「这一步我会这么写」。长卷子上，后者的批改意见显然更管用——这是第 3 章的核心结论。
第 2 章

发现一：预训练期，规划能力怎么「长」出来

三个答案：脑内要装「模拟器」、光会零件不会整机、错题集毒性极强。

🧠 数据格式：给模型装一台「脑内模拟器」

同样的专家轨迹，可以有两种教法。直接作答（w/o WM）：看题直接报动作；世界模型内化（w/ WM）：先在 CoT 里显式推演状态转移——「合成羊毛衫需要毛线+钩针；毛线现在没有；合成毛线需要……」——即把状态转移函数 𝒯: 𝒮 × 𝒜 → 𝒮 内化成深度优先搜索（DFS）式的推理链，再输出动作（论文 §4.1 式 (7)(8)）。结果（论文 §4.1 图 3）：

难度w/o WM avg@8w/ WM avg@8提升
Short（1~5 步）89.598.9+9.4
Middle（6~8 步）46.685.9+39.3
Long（≥9 步）22.768.5+45.8

任务越长，世界模型的优势越大。代价是：直接作答收敛更快、token 更省——它靠背诵记忆，上限却低得多（论文 §4.1 图 4）。点下面的播放，看两种「学生」走同一个 15 步合成任务：

交互演示 · 直接作答 vs 世界模型：15 步合成「羊毛衫」（示意）
演示基于论文图 2 的畜牧养殖实例（合成 cardigan 约 15 步），过程为教学示意。真实结论：长程任务 avg@8 从 22.7% 提升到 68.5%（+45.8），pass@8 从 29.0% 提升到 71.9%（论文 §4.1 图 3）。
下棋时「背棋谱」和「脑内推演」的区别：背谱的人开局犀利，一旦对手走出没背过的局面就抓瞎；会推演的人把棋盘规则装进了脑子，局面越陌生、变化越多，优势越大。长程任务全是「没背过的局面」。

🧱 数据分布：会了所有零件，却拼不出整机

一个诱人的假设是：只要模型学会了所有原子技能（单个合成步骤），就能自动组合出长程规划 h(x) = g(f(x))。论文用数据配比实验泼了冷水：只喂 100% 短任务（Short 区间包含全部原子技能）的模型，短任务 pass@8 高达 93.12%，中程只剩 0.83%，长程 0.00%——组合泛化几乎不发生（论文 §4.2 表 1）。

但反转也很戏剧性：只要掺入 5% 的长程轨迹，能力就被「点燃」——5% 中程数据让中程 pass@8 从 0.83% 跳到 51.88%，5% 长程数据让长程从 0.00% 跳到 11.46%（论文 §4.2）。拖动滑杆看数据配比如何改变三档难度的 pass@8（全部为论文表 1 真实数字）：

☠️ 数据质量：次优轨迹是长程规划的「剧毒」

真实预训练语料不可能全是专家示范，总混着绕路、冗余甚至错误的次优轨迹。论文对比：纯 4 种最优模式 vs 混入 4/8 种次优模式（数据规模、训练步数完全相同）。结论：混入次优轨迹后，短程任务尚有残留能力，中长程任务 pass@8 直接跌到个位数乃至归零；而增加采样次数（pass@k 的 k）也救不回来（论文 §4.3 图 6）。

为什么长程特别惨？因为误差会累积放大：早期一个次优决策不是局部损失，而是让后续所有步骤在错误状态上继续推演：

P(整链成功) ≈ pT
示意模型：若每步独立正确率为 p，T 步全对的概率是 p 的 T 次方。0.9⁵ ≈ 59%，0.9¹⁵ ≈ 21%——步数越多，「还不错的单步」也会被复利成「大概率失败」。
交互演示 · 误差复利：单步正确率 vs 链条长度（示意）
0.90
示意曲线：成功率 = pT。三条参考线对应 Short 5 步 / Middle 8 步 / Long 15 步。真实实验中，4:8 混合次优数据使长程 pass@8 跌至接近 0（论文 §4.3 图 6）。
导航时每拐错一个路口，后面所有「距目的地还有 X 公里」的播报都建立在错误位置上——短途错一个弯还能绕回来，跨省长途错一个弯就是南辕北辙。次优轨迹教给模型的，正是这种「错误路口」。
第 2 章小结：① 内化世界模型 → 长程泛化大幅增强；② 原子技能不会自动组合，但 5% 长程数据即可点燃；③ 次优轨迹因误差复利严重摧毁长程规划（论文 §4 Takeaway）。
第 3 章

发现二：后训练怎么「塑」规划——三区域地图

RL 不是万能塑形刀：它有明确的「不管用 / 管用 / 够不着」三个区域，而 OPD 的疆土比 GRPO 大。

🗺️ 三区域：什么时候该上 RL，上哪种 RL

沿「预训练数据质量」和「任务规划长度」两个维度，论文把后训练的适用空间划成三个区域（论文 §5.2.1 图 7）：

区域含义白话
A · 不必要区各规划模式表现相近（数据本来就干净、任务短）学生 already 全会，教练来了也白来
B · 有效区模式间有明显优劣，RL 能「选出」更好的模式可塑之才，教了就有提升
C · 不支持区长程 + 低质数据：对错动作混在长轨迹里，二元奖励分不出功劳GRPO 够不着——需要 OPD 这种逐 token 细粒度信号

行 = 预训练数据质量（4 最优 → 4最优:8次优），列 = RL 任务规划长度。数值为相对同组 Instruct 模型的 avg@8 均值提升（百分点），摘自论文图 7 与表 3（论文 §5.2.1）。绿 = 提升，红 = 下降，灰 = 持平。
最刺眼的一格：长程 + 最低质量数据（4:8），GRPO 不升反降（−1.6），OPD 却提升 +18.6——这就是 Region C，二元结果奖励的「信用分配」在这里失效，而逐 token 的稠密蒸馏信号仍然有效（论文 §5.2.1 表 3）。
15 道菜的大餐最后只收到一句「不好吃」——厨师根本不知道是第几道菜出了问题（GRPO 的困境）。私教站在旁边逐道点评（OPD），即使学徒基础差、宴席长，也知道每道菜该怎么改。

🧭 为什么 OPD 走得更稳：给参数更新「看方向」

论文不止看分数，还解剖了训练过程本身：对每个 checkpoint 计算权重更新矩阵 ΔW，做 SVD 取前 5 个主方向，比较中途 checkpoint 的更新方向与最终方向的余弦相似度（论文 §5.2.2 式 (11)–(16)）。结果（论文图 9、图 10）：

条件GRPOOPD
短程 + 高质数据方向始终一致 ✅方向始终一致 ✅
长程 + 高质数据早期与最终方向开始偏离 ⚠️方向一致 ✅
长程 + 低质数据方向不一致，甚至梯度消失（曲线贴零平躺）❌仍保持较高一致性 ✅
大雾天开车：GRPO 只有到达目的地才知道开对了没有，雾越大（轨迹越长、噪声越多）方向盘越乱打；OPD 沿路每个路口都有路标，自然走得直。

但 OPD 也有代价：它压低熵、让学生的输出分布向教师收敛——上限被教师锁死。GRPO 在有效区内大 k 采样（pass@k）的天花板反而更高。另外论文提醒：长程场景下 pass@k 会失真——RL 前 pass@k 近零不代表模型没这个能力，只是正确轨迹在预训练分布里太稀有、采不出来（论文 §5.2.1）。

💥 规划知识：满分教师也能把学生教崩

模式能蒸馏，那知识呢？论文设计了一个精巧的「错配实验」：同一个目标（合成羊毛）有两条都正确的配方——配方 A：水+草籽+羊；配方 B：水+棉籽+纺车。学生预训练只学过 A，现在让学 B 出身的教师 B 通过 OPD 来教它（论文 §5.3.1 图 11）。

模型（4 Opt.:4 Sub. 基座）avg@8pass@8说明
Instruct 基线26.1344.03未蒸馏
教师 A / 教师 B100.00100.00两位教师各自域内都是满分
学生 + 教师 A（配方匹配）41.37（+15.24）46.74（+2.71）正常提升
学生 + 教师 B（配方错配）31.50（+5.37）36.60（−7.43）比不教还差 ❌

更细致的解剖：错配蒸馏重创域内（ID）表现——学生原有的配方 A 世界模型被覆写（中程 FA 域 avg@8 暴跌 36.09 分、pass@8 暴跌 43.75 分），而对域外（OOD）只有轻微影响，因为别的域的知识没被直接改写（论文 §5.3.1 表 4）。

川菜学徒跟粤菜师傅学「另一套也对的做法」：师傅确实厨艺满分，但学徒的旧手艺被新配方搅得半生不熟——原来的麻婆豆腐不会做了，新菜也没学透。KL 损失把学生原本写对的 token 当成「错的」来惩罚，等于先拆旧房、新房却没封顶。
KL 动态分析揭示了时间线：训练早期学生先对齐教师的规划模式（KL 顺利下降、奖励上升）；后期进入知识对齐阶段，高互信息的逐点知识超出 RL 更新幅度，训练直接崩溃。结论：知识要靠 SFT 灌入，RL/OPD 只适合塑模式（论文 §5.3.2 图 13–15）。
第 4 章

发现三：多位教师怎么「合体」——MOPD

多教师蒸馏的本质不是「兼收并蓄」，而是「寻找公约数」：收敛到所有教师共享的那个规划模式。

🔧 MOPD 的机制：级联蒸馏，模式收敛（mode seeking）

多教师 On-Policy 蒸馏（MOPD）已是 MiMo-V2-Flash、GLM-5、Nemotron-Cascade 2、DeepSeek-V4 等模型整合多域能力的标准工序，但机制一直不透明（论文 §6.1 表 5）。论文研究其级联（cascaded）形式：学生依次从教师 1、2、…、M 学习，每位教师都用逐 token 的 reverse KL 目标（论文 §6.1 式 (20)）。

关键发现是模式收敛：蒸馏后学生的规划模式分布不是覆盖所有教师的偏好（mode covering），而是快速收缩到教师们共享的那一两种模式上——三个环境里的分布最终同时收敛到同一个「T1 Goal」模板（占比 1.00）（论文 §6.2 图 18）。

徒弟先后拜三位风格不同的师傅，最后形成的不是「三派武功都会一点」，而是三派共同的那套基本功——共享模式被反复强化，独门绝技反而被磨平。这个「求交集」的秉性，决定了下面三种截然不同的结局。

🎭 三种结局：泛化、续学、遗忘

结局由两个维度决定：各环境的规划模式有没有交集、交集冲不冲突（论文 §6.1 图 16）。切换三种类型并播放，看学生的模式分布（横轴 8 个模式：T1~T4 高质量，D1~D4 捷径/干扰）在 Instruct → 依次蒸馏 FA → LF → EA 教师后的演变（全部为论文图 18/20/21 的真实分布）：

交互演示 · MOPD 三种模式下学生的规划模式分布演变（论文真实数据）
数据为幻想炼金（FA）域的模式分布，摘自论文图 18(b)、图 20(c)、图 21(d)。T1 Goal / T2 Step / T3 Planning / T4 Reasoning 为高质量模式（蓝），D1~D4 为捷径干扰模式（灰红）。
模式条件结果（真实数字）
Ⅰ 泛化模式共享且兼容只蒸馏 FA 教师，未见的 LF 域 avg@8 从 34.92 → 52.58；即使基座被低质数据污染（中程 avg@8 仅 0.03），MOPD 后仍恢复到 22.99（论文 §6.2 表 6）
Ⅱ 持续学习模式有共享但部分冲突依次学完三个域后，短程 avg@8 仍保持 FA 91.88 / LF 88.98 / EA 89.77——共享模式保住了旧能力（论文 §6.3 表 7）
Ⅲ 冲突模式无共享且冲突学完 EA 教师后，之前已练到 90.00 的 LF 域 avg@8 崩到 15.62——灾难性遗忘（论文 §6.3 表 7、图 21）
三位老师用三种方言授课：若都夹杂着「普通话」（共享模式），徒弟能借普通话把三门的知识串起来，甚至举一反三到没听过的课（泛化）；若方言各异但普通话还在，至少能一门门接着学（持续学习）；若完全没有共同语言，每换一位老师，上一位的内容就被「洗掉」（灾难性遗忘）。
边界也很清楚：MOPD 只能激活并放大已存在于学生分布中的模式——FA 域训练激活的 T3 模式无法迁移到预训练里没见过 T3 的 LF 域。它提炼「公约数」，但不能无中生有（论文 §6.2 图 17）。

🔬 参数动力学：MOPD 只在基座「附近」小步移动

边界说明
合成环境，规模有限实验在 3 个合成域、Qwen2.5-100M 小模型、词表 3000 上进行——这是「物理实验」的可控性代价，结论向大模型的迁移需要进一步验证
OPD 的结论依赖「理想教师」OPD 有效区更广的前提是教师足够好；教师模式错误时，学生会照单全收（OPD 压低熵、追随教师）
知识注入非 RL 所长「知识靠 SFT、模式靠 RL」的划分来自该环境的互信息分析，真实语料中两者未必如此泾渭分明
反事实合成规则为规模化构建数据，状态转移用了反事实配方（同一物品多条合成路径）；作者说明其贯穿所有实验、不影响相对比较（论文 §3.1、§4.3）

🌟 为什么这项工作值得读

多教师 OPD 已经是工业界整合基础模型能力的既成工序——MiMo-V2-Flash、DeepSeek-V4 用它做跨域整合，GLM-5、Nemotron-Cascade 2 用它做跨阶段能力保持——但「什么时候有效、什么时候翻车」此前没人系统回答（论文 §6.1 表 5）。这篇论文的贡献是把「炼丹」变成「物理」：

一条贯穿三阶段的统一主线：规划知识要在预训练/SFT 阶段以高质量、含长程、含世界模型推演的形式注入；规划模式可以在后训练阶段用 OPD 类细粒度信号安全塑形；多教师合并的成败取决于模式分布有无共享交集。（论文 §8 结论）

对实践者的直接启示：预训练别把长程轨迹洗没了（5% 就够点燃组合泛化，但 0% 就是 0%）；别把次优轨迹当免费数据（误差复利毒性极强）；后训练先判断自己在哪个区域；多教师合并前先检查「模式兼容性」。
