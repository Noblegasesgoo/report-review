第 0 章

热身：智能体的记忆难题

让智能体「记住过去」这件事，此前的主流做法是再请大模型当记忆的「秘书」——而这位秘书既贵，又会悄悄改口供。

🗂️ 记忆系统的两难：「写摘要」还是「翻仓库」

LLM 智能体在长程交互中不断累积对话、动作、工具观察与任务结果。它靠不靠谱，不只取决于当下的推理，更取决于能否从不断膨胀的历史里找回正确的证据——而且要对应到正确的实体、正确的会话、正确的时间状态（论文 §1）。

在此之前的记忆系统大致走两条路，各有硬伤（论文 §1，图 1）：

路线做法硬伤
生成式记忆
Zep / Mem0 / A-Mem / MemoryOS 等		让 LLM 把历史压缩成摘要、记忆卡片、结构化笔记，检索时先查这些「二手材料」记忆管理变成持续的生成开销（token 与时间）；摘要里被省略的细节、被合并的主体、被模糊的时间会削弱对原始交互的可追溯性
原始检索
RAG / GAM 等直接检索原始块		一个字不改，直接对原始记录做词面或向量相似度检索平面检索会混淆不同用户、不同会话、不同时间状态的相似记录；证据分散在多次交互中时容易漏检
生成式记忆像雇一位秘书整理档案：他写的摘要确实好查，但摘要经过他的转述——原件里的关键细节可能被顺手省略或张冠李戴，而且这位秘书按字收费、随叫随计费。原始检索则像不雇秘书、自己去仓库翻箱子：东西都在，但没有编目，想找「去年三月张三说的那句话」得碰运气。Zero-Mem 的想法是第三条路：原件一份不动，但给档案室做两套详尽的索引编目——编目工作全由「不要钱的工具」完成。
论文由此提出核心问题：结构化的记忆访问，真的需要「生成」吗？（Can an agent memory system eliminate LLM calls from every operation outside final question answering?）（论文 §2）

⚖️ 「零 token 记忆操作」到底是什么意思

论文把这套运行方式正式定义为 zero-token memory operations：记忆的构建、组织、路由、检索、证据闭环，以及答题前的证据校准与答题后的答案校准，全部不调用 LLM、不消耗 LLM 输入或输出 token。只有两类计算被单独记账：编码器（embedding 模型）的计算，以及最终问答（final-QA reader）那一次 LLM 推理（论文 §2）。

第 1 章

概念基础：不花 token 的工具箱

要理解 Zero-Mem 为什么敢「不用 LLM」，先认识四件便宜又好用的老工具——它们只做计算，不做生成。

① 「记忆操作」的钱原来花在哪

先统一记账口径。一个记忆系统的完整生命周期可以拆成：构建（把历史存进来）、组织（建索引/结构）、路由与检索（按问题找证据）、校准（筛证据、查答案）。在生成式系统里，这几步里的每一步都可能是一次 LLM 调用——写摘要要 token、抽取三元组要 token、改写查询也要 token，历史越长、调用越频繁，token 与时间开销就成了「经常性支出」（论文 §1）。

Zero-Mem 的账本非常干净：上面每一步的 LLM 开销都是 0。但论文也很诚实地补了一句——零 token 不等于零计算：编码器推理、记忆组织、检索和确定性校准仍然要花算力，只是它们不调 LLM、不烧 LLM token（论文 §Efficiency Comparison）。

LLM 像一位按小时收费的资深顾问：口才好、会综合，但请他整理档案太贵，而且他转述过的东西不算「原件」。Zero-Mem 的思路是：整理档案这种有章可循的活，交给不要钱的编目员（NER）、检索员（BM25/向量）和公证员（确定性校验）去做，资深顾问只在最后出庭陈述时出场一次。

② 四件工具：NER、BM25、向量、PageRank

Zero-Mem 用来看懂和组织历史的全部「智力」，来自四个成熟的非生成式工具（论文 §Method）：

工具干什么白话理解
NER 命名实体识别（如 spaCy）从文本里圈出人名、地点、组织等实体编目员拿荧光笔把每张卡片上的「主角」圈出来
BM25 词面检索按词的重合与稀有度给文档打分按「关键词字面命中」查索引卡：人名、日期、数字、标题一查一个准
稠密向量（BGE-M3）把文本编码成向量，按语义相近程度匹配字面不同但意思相近也能找到——「换工作」和「跳槽」指向同一段记录
Personalized PageRank在图上从指定节点出发做带重启的随机游走，算出每个节点的得分从「与问题相关的实体」出发沿关系网扩散涟漪，看能量最终汇聚到哪些记录上

向量之间的「语义相近程度」用余弦相似度度量——Zero-Mem 用它把问题里的实体对齐到图里真实出现过的实体（论文式 (8)）：

cos(e, ê) = e · ê‖e‖ · ‖ê‖
两个向量夹角越小，值越接近 1，说明问题里提到的实体 ê 和档案里记录的实体 e 越像同一个「主角」。全程只是向量点乘——没有任何生成。
论文特别强调：这些表示只用于索引、播种和打分，不生成、不改写任何记忆内容（论文 §Method / Memory Substrate）。这是「可溯源」承诺的技术底线。
第 2 章

核心方法：Zero-Mem 的四件套

一份不动的原始档案 + 两套互补的编目 + 一个按问题分配权重的分诊台 + 一位铁面无私的核对员。

🗃️ 组件一：可溯源的记忆底座——一份档案，两套编目

Zero-Mem 不用生成的摘要替换原始历史。每个派生单元都完整保留原文、来源标识、会话时间、边界标识等元数据——检出来的每条证据都能回溯到真实交互，而不是某句「模型生成的记忆陈述」（论文 §Memory Substrate）。在此之上建两套互补结构：

编目 A：实体–上下文图（关系视角）。用 NER 圈出每段记录里的实体，连两类边：实体与它出现的记录之间的「共现边」，以及相邻记录之间的「邻接边」（论文式 (3)(4)）：

G = ( Vd ∪ Ve, Ede ∪ Edd )，   w(di, e) = c(e, di)∑e′∈E(di) c(e′, di)
白话翻译：c(e, di) 是实体 e 在记录 di 里出现的次数；一段记录里某实体被提到的占比越高，这条「共现边」越粗。图只记录观察到的共现与邻接，不生成任何推断出来的关系。

编目 B：时间层级（时序视角）。图本身保不住对话的先后顺序与会话状态，所以再把历史按粒度叠成四层（论文式 (5)）：

T(H) = Uturn ∪ Uwindow ∪ Uepisode ∪ Ulocal
轮次（turn）保存原子发言；窗口（window）保留短程上下文；篇章（episode）按语义连续性和会话边界把相邻窗口聚成连贯的「事件区」；局部片段（local span）在证据需要上下文时补上前后文。所有单元都继承原始记录的溯源信息。
像图书馆的双套编目：主题索引卡（图）告诉你「哪些书都提到了爱丽丝」，适合查关系；按上架时间排列的书架（时间层级）告诉你「那段时间先后发生了什么」，适合查来龙去脉。关键是——书本身一本没动，动的只是索引。

🚦 组件二：查询画像与路由——按问题分配两套编目的权重

不同问题要的证据形状不一样：「A 和 B 是什么关系？」该走图；「那天之后发生了什么？」该走时间线。Zero-Mem 为每个问题提取一份轻量画像，全程不借助标准答案（论文式 (6)(7)）：

φ(q) = { subject, keywords, answer-type, temporal-cues, boundary }，   Route(q) ∈ { relational, local }
主体和关键词提供内容锚点；答案类型与时间线索刻画「需要什么结构的证据」；boundary 限定可查的交互范围。路由信号全是确定性的（问法、是否有时间/聚合要求、有无主体锚点），不调用 LLM。

路由不「二选一」，而是决定两套编目在融合时的权重：关系型问题给图视角权重 ρ、层级视角权重 1−ρ；局部型问题反过来（实验中 ρ = 0.6，论文 §Implementation Details）。拖动滑杆感受权重如何改变最终排名（演示候选分数为示意）：

交互演示 · 路由权重如何改写证据排名（示意）
0.60
图视角得分 层级视角得分 融合得分 = ρ·主视角 + (1−ρ)·次视角
三位候选的图/层级单项得分为教学示意值；融合规则与论文式 (13) 一致：Sfuse(d) = ρ·Ŝprimary(d) + (1−ρ)·Ŝsecondary(d)。完整模型中两个视角都会执行，路由只控制相对权重（论文 §Query-Conditioned Evidence Routing）。
前台分诊：病人说「我和家人的关系」（关系型），优先转给查「主题索引卡」的科室；病人说「我上周三之后怎么了」（局部型），优先转给查「时间线」的科室。但两个科室都会出诊，只是意见权重不同。

🔍 组件三：双视角检索与证据闭环——涟漪扩散 + 从章到句

图视角：激活扩散 + Personalized PageRank。先用余弦相似度把问题实体对齐到图中实体，作为「火种」；然后让激活沿共现句子向外扩散——一个实体若与已激活实体在「和问题相关的句子」里共同出现，就得分（论文式 (8)(9)）。扩散结果与上下文先验合成重置向量 rq，最后用 Personalized PageRank 在整张图上摊分能量（论文式 (10)）：

πq = (1 − γ)rq + γP⊤πq
γ 是阻尼系数（实验取 0.6）：每次游走以 1−γ 的概率「跳回」与问题相关的种子，以 γ 的概率沿边继续走。迭代收敛后，上下文节点上的 PageRank 值就是图视角的排名——能量最终汇聚的记录，就是「关系网里离问题最近」的证据。
交互演示 · 图视角的能量扩散（示意）
示意网络：● 圆形 = 实体节点，■ 方形 = 上下文（记录）节点。播放顺序对应论文流程：对齐问题实体 → 沿共现句子扩散激活 → PageRank 收敛后得分最高的记录被取走。网络结构与数值为教学示意。

层级视角：粗到细的钻取。每个单元同时按「语义相关性」和「与查询画像的结构兼容性」（主体一致、时间有效、边界一致、答案类型匹配、词面支持）打分，然后从粗到细逐层下钻（论文式 (11)）：

Uepisode → Uwindow → Uturn → Ulocal
篇章先圈出相关的「事件区」，窗口把范围收窄，轮次亮出原始证据；若证据依赖前后文，再补上局部片段。与图视角不同，这一路显式保住了顺序、时间局部性与会话级上下文。

融合与闭环。两路排名先做按查询的 min-max 归一化，再按路由权重 ρ 融合成主证据 M(q)；然后证据闭环从图视角补充「关系桥接」记录、从层级视角补回相邻轮次或局部片段，按来源标识去重，得到紧凑的闭环证据集 C(q)（论文式 (12)(13)(14)）。

两位侦查员分头查案：一位沿「人物关系网」摸排（图），一位按「案发时间线」梳理（层级）。汇总时先按案件类型决定谁的意见权重高，再互相补充——关系网发现的线索要配上前后时间线，时间线上的关键节点要补上关系背景，最后把重复笔录合并，形成一份完整卷宗。

✅ 组件四：确定性校准——答题前后各设一道「安检」

答题前：证据校准。先做硬过滤——丢掉违反溯源或查询边界约束的候选；再按主体、时间、答案类型的兼容性排序，产出最终证据集 R(q)。过滤只执行规则、排序不改写内容（论文式 (15)）：

R(q) = Rankφ(q) ( Filter ( C(q), φ(q) ) )
到这一步为止，整条流水线没有调用过一次 LLM。接下来，唯一一次 LLM 调用发生：reader 基于 R(q) 产出初始答案 a₀。

答题后：答案校准。对可确定性检查的题型，从证据本地抽取候选集 A(q)，再做三类检查：证据支持度、答案类型、格式。规则非常克制——a₀ 有证据支持且格式合规就原样保留；标量答案只在 A(q) 中存在唯一类型兼容候选时才替换；列表类答案做逐条修剪与规范化；若没有可用的确定性修正，一律保留 a₀（论文式 (16)）。

法庭的「证据核对员」：开庭前剔除来路不明的证物（边界/溯源过滤）；宣判后核对判决书——答案必须能在卷宗里找到出处、类型格式必须合规。核对员只查不改口供：没有铁证就维持原判，绝不自由发挥。
至此，记忆的构建、组织、路由、检索、闭环、双端校准全部完成，LLM 调用次数：记忆操作 0 次 / 最终问答 1 次（论文图 2、§Deterministic Evidence Calibration）。
第 3 章

实验结果：不花钱，还更能打？

两个基准、两种底座模型、十个对手——先看准不准，再看贵不贵，最后拆开看每个零件的贡献。

🧪 实验设置：把「记忆管线」单独拎出来比

两个互补基准（论文 §Experimental Setup）：LoCoMo（arXiv:2402.17753）考察多会话长程对话记忆，含单跳、多跳、时间推理、开放域四类问题；HotpotQA（arXiv:1809.09600）的记忆评测变体把金标准文档混入干扰段落，构造 56K / 224K / 448K token 三档上下文，考察长文本多跳检索。底座模型用 GPT-4o-mini（闭源）与 Qwen2.5-14B（开源）各跑一遍；所有方法共用同一个最终答题器与同等上下文预算，因此差异全部来自记忆管线本身。对手包括无记忆的 LONG-LLM、RAG（2048 token 切块取 top-5），以及记忆系统 A-Mem、Mem0、MemoryOS、LightMem、SimpleMem、CompassMem、GAM（LoCoMo 上另有 HippoRAG）。阻尼系数 γ 与路由权重 ρ 均设 0.6，检索预算统一 top-5，硬件 RTX 4090、四线程并发。

🌟 为什么这篇论文值得记住

此前的高效记忆系统（如 SimpleMem、LightMem）的思路是减少生成式开销——压缩 token、把小模型换进记忆管线。Zero-Mem 则直接把问题推到极限：记忆操作的生成开销能否归零？它用「保留原始记录 + 双视图结构化检索 + 确定性校准」给出了肯定答案，并且在两个基准上以零记忆 token 的代价拿到了有竞争力甚至第一的成绩（论文 §Conclusion）。

大家一直在比赛「怎么把秘书的工资压低」，Zero-Mem 直接问：整理档案这件事，为什么需要一位会写作的秘书？给它两套好编目和一位铁面核对员就够了——作家只需要在最后写结案陈词时出场。
一句话总结：有效的智能体记忆，不需要对过去生成中间表示——可溯源的证据选择，是生成式记忆管线之外一条切实可行的路（论文 §Conclusion）。
